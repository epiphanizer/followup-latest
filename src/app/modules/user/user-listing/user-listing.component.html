How to work a duplicate group

These checks mirror the live login and merge-script behavior now wired through the API.
1
Review the suggested target
The first highlighted account is the most recent active record. Keep it unless downstream ownership or audit history suggests another account should remain primary.
2
Choose a source account
Generate merge SQL only from a non-target account into the selected target. The API blocks identical source/target pairs and returns the same validation the smoke harness now checks.
3
Review the script before running it
Merge workups stay wrapped in a rollback-first transaction and call out trigger behavior. Review the counts, ownership rules, and side effects before swapping rollback for commit.
Admin access is required to review duplicate login accounts and generate merge scripts.
